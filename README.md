# Nahathai Wonganawat

Computer science student building games, interactive web projects, and machine learning experiments.

## What I work on

- 2D games built with Cocos Creator and TypeScript
- Frontend and Firebase-based web applications
- Machine learning and graphics experiments
- Coursework projects that show how I design, implement, and iterate

## Featured projects

### [Final NTHU](https://github.com/nahathaiw/final_nthu)
A campus-themed Cocos Creator game with exploration, mini-games, Firebase login, and leaderboards.

### [Web Mario Platformer](https://github.com/nahathaiw/web-mario-platformer)
A Super Mario-inspired 2D platformer built with Cocos Creator and TypeScript.

### [Lab10 - NS-Shaft](https://github.com/nahathaiw/lab10-ns-shaft)
A vertical survival platform game with physics, hazards, conveyor platforms, and score tracking.

### [Lab09 - Different Color](https://github.com/nahathaiw/lab09-different-color)
A visual puzzle game where players identify the subtly different tile as the difficulty increases.

### [Lab08 - Another Slime AI](https://github.com/nahathaiw/lab08-another-slime-ai)
A Cocos Creator AI project exploring pathfinding, wandering, chasing, and behavior strategies.

### [Lab06 - Simple Forum](https://github.com/nahathaiw/lab06-simple-forum)
A Firebase forum exercise with authentication, posting, and real-time updates.

## Repository guide

- `final_nthu` and `web-mario-platformer` are the best starting points for game development work.
- `lab08-another-slime-ai` shows AI and movement logic.
- `lab06-simple-forum` and `lab05-asynchronous` show frontend and JavaScript practice.
- Older repositories are preserved coursework projects and Git practice exercises.
